# Enthalix

**Enthalix** is the name under which GreenMEP is developing open-source building energy
modelling software: building models (IFC) in, EnergyPlus energy models out, and the
building's measured operation compared back against the model.

This repository is the project's public placeholder. The software is in private
development and is not yet released; code will be published here when it is.

- Name first recorded here: 23 September 2026
- Maintainer: David Ellis, GreenMEP

"Enthalix" is used by GreenMEP as the name of this project. Please do not use it for
another product or project.
